# Events V2 Webhook

Fetch the authoritative contract before implementing:

```bash
curl -fsSL 'https://docs.appcharge.com/api-reference/events/v2/introduction.md'
```

Event payload index (discover all event types):

```bash
curl -fsSL 'https://docs.appcharge.com/llms.txt' | grep 'api-reference/events/v2/'
```

Events Center setup (Dashboard registration and event toggles):

```bash
curl -fsSL 'https://docs.appcharge.com/guides/events/about-the-events-center.md'
```

Example event payload (order completed):

```bash
curl -fsSL 'https://docs.appcharge.com/api-reference/events/v2/order/order_completed.md'
```
